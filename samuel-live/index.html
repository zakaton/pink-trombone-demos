Open the Pink Trombone page in another tab and click it once so it can make sound. Wear headphones if you can: Samuel listens to the microphone, so the speakers would feed back into it. Samuel's articulation is built for a vocal tract length of 44: a different length scales the tongue, constriction and lip positions with it, so the same sounds are made in a longer or shorter tract. The graphs show the last few seconds of what Samuel is hearing, as the parameters it sends.
