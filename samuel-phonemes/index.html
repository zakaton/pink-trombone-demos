Each value is normalised by its range and weighted by these sliders, and the closest map wins. Smoothing averages neighbouring frames, and a new phoneme is only accepted once it has won for the number of stability frames (about 12 ms each), which stops flicker. If even the closest map is further than the max distance, the result is "?". Settings are saved in the configuration.
